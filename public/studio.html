Add a destination with a stream key instead

YouTube: YouTube Studio → Go live → Stream — copy the Stream key (ingest a.rtmps.youtube.com/live2).

Facebook: facebook.com/live/producer → Streaming software — copy the Stream key (ingest live-api-s.facebook.com:443/rtmp). A persistent key also works for Facebook groups.

Custom: paste a full rtmp:// or rtmps:// URL including the key (Twitch, restream servers, nginx-rtmp…).
